# SPI (Serial Peripheral Interface)

## Overview

This directory contains the RTL implementation of a Serial Peripheral Interface (SPI) developed as part of the Tiny SoC project.

The SPI peripheral enables high-speed synchronous serial communication between a master and one or more slave devices. The implementation follows the master-slave communication model, where the master generates the serial clock and controls data transfer.

The design has been developed using a modular architecture to simplify verification, integration, and future scalability.

## Features

- Master and Slave implementation
- Full-duplex serial communication
- 8-bit data transfer
- Programmable chip select (CS)
- Serial clock (SCLK) generation
- MOSI (Master Out Slave In)
- MISO (Master In Slave Out)
- Finite State Machine (FSM) based controller
- Busy and Done status indication
- Modular RTL architecture
- APB-compatible wrapper for Tiny SoC integration

---

## SPI Interface

| Signal | Direction | Description |
|---------|-----------|-------------|
| clk | Input | System clock |
| rst | Input | Active-high synchronous reset |
| start | Input | Starts SPI transaction |
| tx_data[7:0] | Input | Data to be transmitted |
| rx_data[7:0] | Output | Received data |
| sclk | Output | Serial clock generated by master |
| mosi | Output | Master Out Slave In |
| miso | Input | Master In Slave Out |
| cs | Output | Chip Select (Active Low) |
| busy | Output | Indicates SPI transaction is active |
| done | Output | Indicates transaction completion |

## Module Description

### spi_master.v

Implements the SPI Master controller responsible for:

- Clock generation
- Chip Select control
- Serial transmission
- Serial reception
- Transaction sequencing

---

### spi_slave.v

Implements the SPI Slave controller.

Responsibilities include:

- Receiving serial data from MOSI
- Sending serial data on MISO
- Shift register operations
- Synchronization with master-generated clock

---

### spi_wrapper.v

Provides the interface between the SPI peripheral and the APB bus used in the Tiny SoC.

Responsibilities include:

- Register interface
- APB read/write operations
- Control signal decoding
- Status register generation

## Functional Operation

The SPI transaction follows the sequence below:

1. Master asserts **Chip Select (CS)**
2. Master generates **Serial Clock (SCLK)**
3. Data is shifted out through **MOSI**
4. Slave simultaneously shifts data onto **MISO**
5. Eight clock cycles complete one byte transfer
6. Master deasserts **Chip Select**
7. Transaction completes and the **Done** signal is asserted
